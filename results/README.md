# Test results

Raw output of all tests, grouped by tag (the start of the file name). The contents are kept as they were. The `deploy/...` paths in them are the old locations from before the 2026-10-18 directory reorganization. Before publication the host name was replaced with `<host>`. Other placeholders (`<tmp>`, `<work>`, `<rocm>`, `<oneapi>`, `<scratch>`) stand for local folders; the header of each file says what they stand for, except `<work>` in `pr2918-builds.txt`, a temporary folder. In the mutant files, `<worktree>` (10-20) and `<repo>` (10-18) are the checkout the mutants were copied from.

The long-document requests are taken from Strata's documentation (`docs/*.md` and `README.md`). Some files (for example `*-trace.txt` and `ple_hint_probe.jsonl`) contain excerpts of these documents or of model answers. `ple_hint_count.cpp.txt` and `pr2918-contract.cpp.txt` contain code copied from Strata's `src/ngram/ple_reader_test.cpp`, and `pr2918-mutants.diff.txt` contains excerpts of its `src/kernels/ngram.cpp`. The commands were rerun on 2026-10-18. Apart from the line that names the generating script, which now shows the new path, 6 p50 values in the Poisson table of `SUMMARY.md` changed: for R1 to R2 A/A, the upper median was stored at the time, and `report.py` now recalculates them from the per-request data with nearest-rank, the same as for all other groups. All other numbers are unchanged.

python3 bench/report.py results > results/SUMMARY.md
python3 -B bench/ab_summary.py v431-1 v441-1 v441pf v441-2 v431-2 > results/AB-0.1.44.1.md

  "z-off-1=ZFS release --no-ple-prefetch=z-off-1" "z-lk-1=ZFS branch=z-off-1" "z-hint-1=ZFS release default=z-off-1" \
